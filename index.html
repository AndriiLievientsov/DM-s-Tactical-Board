          🎲 DM's Tactical Board

          Стол мастера для игры вживую: ты управляешь, игроки смотрят на второй экран.

          С чего начать

          1. 🖼️ Карта — загрузи картинку карты (или перетащи файл на поле).
          2. Положи токены: перетащи картинки на карту или добавь их в Библиотеку.
          3. Двойной клик по токену — его карточка: HP, КД, скорость, атаки, статусы. Правый клик — быстрое меню.
          4. Вкладка Инициатива → «⬇️ Импорт токенов» → «🎲 Бросить всем» → «▶ Следующий ход».
          5. 🖥️ Игрокам — открой окно для проектора/ТВ: там нет панелей, HP и скрытого тумана.
